# Aditi Suvarna — Portfolio

A responsive visual design portfolio built with HTML, CSS, JavaScript and SVG.

**Website:** https://aditisuvar-collab.github.io/aditi-portfolio/

## Hosting

Hosted for free on GitHub Pages from the `main` branch, `/(root)` directory. No build step, API keys or server are required.

## Editing

- `index.html`: page content and contact links
- `style.css`: layout and visual styles
- `script.js`: interactive cards and experience overviews
- `botanical-label.svg` and `spatial-story.svg`: original illustrative covers

The SVG covers illustrate practice areas; they are not client project images. Google Fonts has local font fallbacks. Contact buttons open the visitor’s email app.
